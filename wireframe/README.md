# Todo app wireframe

Open `index.html` in this folder directly in a browser to view the static, low-fidelity wireframe. It has no dependencies and does not require the Node server.

The wireframe follows the current application order: page heading, create/edit form, weather and AI planning tools, task list, and status feedback. Dashed boxes indicate conditional states rather than content that appears at all times.

The layout adapts to narrow screens. Use the browser's Print command to export it as a PDF if needed.

CRUD interactions represented:

- Create: enter a name and urgency, then select Add todo.
- Read: show saved tasks, task count, and an empty state when appropriate.
- Update: Edit populates the form; Save changes submits it; Cancel edit resets it. The row urgency dropdown updates urgency directly.
- Delete: Delete opens a confirmation dialog before removing the task.

This is a visual planning artifact. Its controls do not perform application actions.
